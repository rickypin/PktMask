## 关键问题汇总

### 🔴 高优先级问题（必须修正）

#### P1: 配置字段缺失
- **问题：** `UISettings` 中缺少 `last_input_mode` 字段
- **影响：** 配置保存时会抛出 `AttributeError`
- **修正：** 在 `src/pktmask/config/settings.py` 中添加字段
- **状态：** ✅ 已在文档中修正

#### P2: 向后兼容属性设计错误
- **问题：** `@property` 装饰器不能在 `__init__` 中定义
- **影响：** 代码会抛出 `SyntaxError`
- **修正：** 改用普通方法实现向后兼容
- **状态：** ✅ 已在文档中修正

### 🟡 中优先级问题（建议修正）

#### P3: 输出路径生成逻辑不一致
- **问题：** 单文件和目录的输出路径生成逻辑相同（错误）
- **影响：** 目录输入时输出位置错误
- **修正：** 根据 `input_type` 选择正确的父目录
- **状态：** ✅ 已在文档中修正

#### P4: 缺少单文件验证方法
- **问题：** 只有 `validate_input_directory`，缺少 `validate_input_file`
- **影响：** 单文件输入时无法进行有效验证
- **修正：** 添加 `validate_input_file` 和 `validate_input_path` 方法
- **状态：** ✅ 已在文档中修正

### 🟢 低优先级问题（可选修正）

#### P5: Emoji 图标兼容性
- **问题：** ComboBox 中的 emoji 可能在某些系统不显示
- **影响：** UI 显示不美观
- **建议：** 使用纯文本或 Qt 图标
- **状态：** ⚠️ 建议在实施时考虑
