# PktMask CLI 全面测试计划（基于代码审查）

## 代码审查结果

### 实际支持的命令（来自 __main__.py）
1. **无参数** - 启动 GUI（通过 callback）
2. **process** - 处理 PCAP/PCAPNG 文件
3. **validate** - 验证文件但不处理
4. **config** - 显示配置摘要

### 实际支持的参数（来自 commands.py）

#### process 命令参数
- `input_path` (位置参数，必需) - 输入文件或目录
- `-o, --output` (可选) - 输出路径，默认自动生成
- `--dedup` (布尔) - 启用去重
- `--anon` (布尔) - 启用 IP 匿名化
- `--mask` (布尔) - 启用载荷掩码
- `--mask-protocol` (字符串，默认 "auto") - 掩码协议 (tls|http|auto)
- `-v, --verbose` (布尔) - 详细输出

#### validate 命令参数
- `input_path` (位置参数，必需) - 输入文件或目录
- `-v, --verbose` (布尔) - 详细输出

#### config 命令参数
- `--dedup` (布尔) - 启用去重
- `--anon` (布尔) - 启用 IP 匿名化
- `--mask` (布尔) - 启用载荷掩码

### 环境变量支持
- `PKTMASK_LOG_LEVEL` - 设置日志级别 (DEBUG|INFO|WARNING|ERROR|CRITICAL)
